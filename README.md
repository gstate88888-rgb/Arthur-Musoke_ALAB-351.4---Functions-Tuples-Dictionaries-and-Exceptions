ALAB 351.4 - Functions, Tuples, Dictionaries, and Exceptions

What I Learned

Part 1:
- Created functions with and without parameters.
- Used return statements to return values from functions.
- Stored function results in variables.
- Used functions to simplify a calculator program.

Part 2:
- Created and accessed tuples.
- Learned that tuples are immutable and cannot be changed.
- Used dictionaries to store key-value pairs.
- Added, updated, and displayed dictionary data.
- Calculated averages from tuples stored in a dictionary.

Part 3:
- Used try/except blocks to handle errors.
- Raised a custom ValueError when dividing by zero.
- Used a finally block to run code whether an error occurred or not.
- Caught generic exceptions to prevent program crashes.

Exception Handling Examples:
- Division by zero was caught using ValueError and ZeroDivisionError.
- Invalid user input was caught using ValueError.
- Attempting to modify a tuple raised a TypeError that was handled.
- Converting an invalid string to an integer raised an exception that was caught.
